# Decky Eclipse

Steam Deck에서 ECLIPSE 최적화 모드를 다운로드·설치·복구하는 한국어 Decky Loader 플러그인입니다.

**현재 버전: v0.2.4** · [릴리스 다운로드](https://github.com/sunim87/decky-eclipse/releases/latest) · [58개 지원 게임](docs/SUPPORTED_GAMES.md) · [변경 내역](CHANGELOG.md)

## 주요 기능

- Steam 라이브러리와 microSD에 설치된 게임 탐색, 비 Steam 게임 바로가기 인식
- ECLIPSE 배포 목록 58개 전체의 자동 다운로드·압축 해제·백업·설치·원상 복구
- 게임별 설정 화면에서 설치·복구, 전체 진행률 및 다운로드·백업·복사 상태 표시
- 게임 목록에서 Proton, Steam Linux Runtime, Steamworks 재배포 패키지, ProtonPlus 등 도구 제외
- 필요한 시작 옵션과 Proton DLL 자동 설정 및 설치 전 상태로 복구
- 대용량 파일 구간 다운로드·재시도, SHA-256 검사, 게임 실행 중 설치 차단

| 표시 | 의미 |
|---|---|
| 🟢 지원 | 모드가 있고 빌드 불일치가 확인되지 않음 |
| 🟠 빌드 다름 | 설치된 Steam 빌드와 모드 지원 빌드가 다름 |
| 🔴 지원안함 | 해당 게임을 배포 목록에서 찾지 못함 |

빌드 ID가 명시되지 않았거나 비 Steam 게임이라 비교할 수 없는 경우에는 빌드 불일치로 판정하지 않습니다.

## 설치 및 사용

1. [v0.2.4 릴리스](https://github.com/sunim87/decky-eclipse/releases/tag/v0.2.4)에서 `Decky-Eclipse-v0.2.4.zip`을 다운로드합니다.
2. Decky Loader 설정에서 개발자 모드를 켜고 ZIP 설치 기능으로 설치합니다. 기존 버전은 같은 플러그인으로 업데이트됩니다.
3. Decky 메뉴에서 **Decky Eclipse**를 열고 게임을 선택합니다.
4. 게임을 완전히 종료한 뒤 **모드 다운로드 및 설치**를 누릅니다.
5. 다운로드 → 파일 검사 → 압축 해제 → 원본 백업 → 파일 적용 → 필요한 시작 옵션 설정이 자동 진행됩니다.
6. 원래 상태로 돌아가려면 같은 게임의 **원상 복구**를 누릅니다.

빌드가 달라도 설치 버튼을 사용할 수 있습니다. 다음 확인창에서 **예**를 선택한 경우에만 설치합니다. **아니오** 또는 창 닫기는 다운로드와 파일 변경 없이 취소합니다.

> 설치된 게임 버전과 모드 지원 버전이 다릅니다. 설치하시겠습니까?

확인창에는 설치된 Steam 빌드와 모드 지원 버전이 함께 표시됩니다. 빌드 불일치 확인은 파일 설치를 허용하는 기능이며, 다른 버전에서의 게임 호환성을 보장하지는 않습니다.

## 게임별 설치 조건

- [지원 게임 목록](docs/SUPPORTED_GAMES.md)에 지원 버전, 선택한 프리셋과 설치 조건을 정리했습니다.
- 여러 변형이 있는 모드는 정품 및 Steam Deck 성능 우선 프리셋을 기본 선택합니다. 다른 기기·품질용 변형은 복사하지 않습니다.
- 일부 배포본은 제작자가 정품 호환성 미확인을 안내합니다. 해당 내용은 게임 설정에서도 표시합니다.
- **Starfield**는 제작자가 필수로 지정한 약 8.9 GB 텍스처 압축 파일을 추가 다운로드합니다. 원본 백업과 압축 해제 공간도 필요합니다.
- **Need for Speed Heat**는 Proton 프리픽스에도 DLL을 설치합니다. 프리픽스가 없으면 게임을 한 번 실행하고 종료한 뒤 설치하세요.
- **Alan Wake 2** 같은 비 Steam 게임은 실제 게임 실행 파일과 영어 이름으로 Steam에 추가하는 것이 좋습니다.
- 게임 내 그래픽 메뉴 조작, SDWEAK 설치, Proton 버전 변경, 오버클럭은 자동화하지 않습니다. Star Wars Outlaws의 OS·Proton 종속 사전 생성 셰이더 캐시는 제외합니다.

## 백업과 복구

교체·제외할 원본 파일은 Decky의 플러그인 설정 폴더 `backups/<appid>/original`에 보관합니다. 설치 기록을 먼저 저장한 뒤 게임 파일을 변경하며, 오류 발생 시 자동 복구를 시도합니다. 새로 추가한 파일과 빈 폴더는 복구할 때 정리합니다.

시작 옵션과 Proton DLL도 설치 전 상태를 보관합니다. 시작 옵션 설정 전에 화면이 닫히면 다음 실행에서 이어서 처리합니다. 실패하면 **시작 옵션 설정 다시 시도**를 사용할 수 있습니다.

게임 업데이트나 다른 모드가 적용 파일을 변경한 경우에는 덮어쓰지 않고 복구를 중단하며 백업을 보존합니다. 게임 이동·삭제·백업 손상에 대한 강제 복구는 제공하지 않습니다. 백업은 설치 전 상태이므로 원래 다른 모드가 있었다면 그 상태로 복구됩니다. 플러그인 제거 전에는 먼저 원상 복구하세요.

원본을 제외하는 모드도 복구용 백업을 유지하므로, 제작자가 안내한 삭제 용량만큼 저장 공간이 즉시 늘어나지는 않습니다. 다운로드·압축 해제 임시 파일은 설치 후 정리합니다.

## 배포 출처와 검증

모드 배포 목록은 [Steam Deck Base](https://www.steamdeckbase.org/optimization)를 사용합니다. 사이트 형식 변경이나 연결 실패 시 마지막 캐시 또는 동봉 목록을 사용합니다. GitHub 설치 ZIP에는 ECLIPSE 모드 파일을 포함하지 않으며, 사용자가 설치할 때 원 배포 서버에서 다운로드합니다.

`recipes.json`에는 실제 배포 압축 파일을 검사한 다운로드 주소·SHA-256·프리셋·파일 경로·지원 빌드를 기록합니다. 주소나 파일이 바뀌면 설치 규칙 업데이트가 필요합니다. 해시 일치는 검사한 파일과 동일하다는 의미이며, 제작자 서명 또는 악성 코드 검사 결과는 아닙니다.

HTTPS 인증서와 호스트 이름을 검증합니다. Decky 내장 Python의 CA 경로 문제를 보완하기 위해 SteamOS 인증서 저장소와 동봉된 certifi 공개 CA 묶음을 사용합니다.

## 개발

Node.js 24, Python 3.11 이상이 필요합니다.

```sh
npm ci
npm run typecheck
npm run test:ui
python -m unittest discover -s tests -v
npm run build
python scripts/package.py
```

설치 ZIP과 SHA-256 파일은 프로젝트 폴더의 상위 디렉터리에 생성됩니다. Linux x86-64용 7-Zip 실행 파일과 라이선스를 동봉하며, SteamOS 루트 파일 시스템 변경이나 sudo는 필요하지 않습니다.

GitHub Actions는 소스·화면 테스트와 빌드를 수행합니다. `v0.2.4`와 같은 버전 태그를 푸시하면 같은 검사를 거쳐 설치 ZIP과 체크섬을 GitHub Release에 게시합니다.

배포 자료 갱신과 실제 압축 파일 검사 방법은 [유지보수 안내](docs/MAINTAINING.md)를 참고하세요.

## 검증 범위

- 실제 배포 압축 파일로 58개 게임의 테스트 폴더 설치·복구 검사 통과: [검사 기록](docs/archive-validation.json)
- v0.2.4 회귀 테스트 25개, React 화면 테스트, 타입 검사 및 빌드 통과
- Steam Deck에서 HTTPS 다운로드·해시 검사·목록 갱신과 플러그인 로드 확인
- 검은 신화: 오공의 지원 빌드 및 적용 파일 2개의 해시, 원본 백업 확인

58개 게임 전체의 실제 게임 실행·성능 향상을 검증한 것은 아닙니다. 테스트 폴더 검사에서 Steam 시작 옵션 저장 확인은 테스트 어댑터로 대체합니다.
